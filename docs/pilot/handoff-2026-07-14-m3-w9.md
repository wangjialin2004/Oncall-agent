## 2. 架构心智模型（含 W9）

```text
POST /api/assistant (SSE)
  body 可选：Simulate / PreferParallel（评测钩子，产品流量勿乱开）
  → HarnessService.stream
      runtime holder
      → timeout：有证据 → timeout_soft_close（W9）；否则 fallback
      → route（concrete-incident override 可选）
      → context（ContextState；resume rehydrate）
      → plan → clarify?
      → [可选] Simulate → prometheus 工具故障注入（W9 / RE2）
      → [可选] force seed delegate_parallel 跨域（W9 / P1，默认开）
      → [可选] force seed delegate_to_expert（默认关）
      → [可选] aux_probe（off|serial|parallel）
      → tool/model loop
           · slow_path_tool_cap 抑制同名工具狂刷（W9）
           · dynamic max_steps / route timeout profile
           · parallel readonly tool_calls
           · delegate_to_expert / delegate_parallel
           · 共享 sub_harness 内核
           · replan：主工具失败亦可（W9 REPLAN_ON_PRIMARY_FAIL）
           · knowledge / investigation early close
      → verify → re_evidence → post replan?
      → 若工具全失败且模型空答 → 合成证据缺口正文（W9 收口补丁）
      → corrective 缺口前缀?
      → suggested_actions + 升级块（W9 HITL）
      → observe_agent_run metrics（W9）
      → stamp recent_turns
      → [可选] trace export
      → complete（suggested_actions / escalation / re_* 计数）
```
