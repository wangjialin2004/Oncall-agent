## 2. 当前架构心智模型（接手必懂）

```text
POST /api/assistant (SSE)
  → HarnessService.stream
      runtime holder（供外层 timeout 落 checkpoint）
      → route → context（ContextState 优先）→ plan → clarify?
      → [可选] force seed delegate_to_expert
      → tool/model loop（步数/预算/无进展/单步超时）
      → verify
      → [可选] re_evidence × N（默认 1）→ 再 verify
      → corrective 缺口前缀?
      → stamp recent_turns + last_answer_summary
      → complete
```

| 能力 | 默认 | 说明 |
|---|---|---|
| 只读诊断 | 是 | **禁止**自动重启/回滚/扩缩容执行 |
| Re-evidence | **开** | 低置信/有 gaps 再补 1 轮工具 |
| Force 首委派 | **关** | `HARNESS_FORCE_EXPERT_DELEGATION=false` |
| 证据类型细匹配 | **开** | 计划 required_evidence ↔ 工具名 |
| 变更数据源 | **无** | `gap=missing_change_datasource`，禁编造版本/操作人 |
| Checkpoint | **开** | 默认 conservative；timeout 会 best-effort 落盘 |
| Stateful 白板 | **开** | 每轮 complete stamp Q/A |
